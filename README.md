# Task-1-Database-Schema-Design
# Library Management System Database

## Objective
Designed a normalized database schema for a Library Management System.

## Tools Used
- MySQL Workbench
- MySQL Server

## Entities
- Authors
- Books
- Categories
- Members
- Loans

## Relationships
- Author -> Books (1:M)
- Category -> Books (1:M)
- Member -> Loans (1:M)
- Book -> Loans (1:M)

## Key Concepts Applied
- DDL
- Primary Key
- Foreign Key
- Constraints
- Normalization
- ER Diagram
